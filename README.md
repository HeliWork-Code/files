# 云盘

一个由 GitHub Pages 托管的静态文件分享站点。访客可以浏览、搜索和下载仓库中 `storage/` 文件夹里的公开文件。

## 部署

1. 将此项目放进 GitHub 仓库，并推送到 `main` 或 `master` 分支。
2. 在仓库 **Settings → Pages → Build and deployment** 中，将 **Source** 设为 **GitHub Actions**。
3. 推送后，GitHub Actions 会生成文件目录并部署网站。发布地址可在 **Settings → Pages** 查看。

## 添加或删除文件

把要分享的文件放进仓库的 `storage/` 文件夹，提交并推送。文件夹结构会显示为网站中的目录，部署完成后访客即可下载。删除文件时，从仓库中删除对应文件并推送即可。

也可以点击网站右上角的“管理文件”，在 GitHub 仓库中上传或管理文件；这需要有仓库写入权限的 GitHub 账号。

## 注意

- GitHub Pages 是静态托管；网站本身不能接收并保存访客上传，也没有用户账号或权限管理。
- `storage/` 中的内容会公开发布。不要放入私人文件、密码、令牌或其他敏感信息。
- GitHub 仓库有文件大小和带宽限制；大型文件或大量下载更适合专门的对象存储/CDN。
